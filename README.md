# Birthday Surprise for Gayatri Mam ❤️

## Files
- `index.html`, `style.css`, `script.js`: the website
- `images/gaitri.jpg`: Mam's main photo (already added)
- `images/memory1.jpg` to `memory6.jpg`: optional gallery photos

## Replace the main photo
Save a new photo as `images/gaitri.jpg` (same name) and overwrite the old one. A portrait photo works best.

## Add gallery photos
Put photos in the `images` folder named `memory1.jpg`, `memory2.jpg` ... `memory6.jpg`. Empty slots show "Add photo" until you do.
Want more than six? Copy one `<figure>...</figure>` line in `index.html` and change the number.
Tip: resize photos to about 1200px wide so the site loads fast.

## Host on GitHub Pages
1. Create a new GitHub repository (for example `gaitri-mam-birthday`).
2. Upload all the files, keeping the `images` folder.
3. Go to Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute, your link appears there. Send it to Mam!

## Music
The soft "Happy Birthday" melody is generated inside the browser, so no music file is needed. It starts only after the "Open Your Special Surprise" tap, and the 🎵 button turns it ON/OFF.
To use your own song instead, tell me and I can swap it in.

## Note
Fonts load from Google Fonts, so the site needs internet to look its best.
